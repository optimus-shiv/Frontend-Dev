Question 1:  Explain the difference between frontend, backend, and full-stack development with
suitable real-world examples.
Answer:  Frontend Development: Focuses on what users see and interact with on a website or app (UI/UX).
Example: Buttons, forms, and layout on Instagram’s app.
Tech: HTML, CSS, JavaScript, React.

Backend Development: Handles the server, database, and application logic behind the scenes.
Example: Storing and retrieving Instagram posts and comments.
Tech: Node.js, Python, Java, SQL.

Full-Stack Development: Combines both frontend and backend skills, managing the complete web application.
Example: Building Instagram end-to-end: user interface + server + database.
Tech: MERN stack (MongoDB, Express, React, Node.js).

Question 3: Describe how a browser requests and displays a web page from a web server.
Answer: Browser Request and Display Process (Short Textbook Answer):
Browser sends a request to the server using the URL.
DNS translates the domain name to the server’s IP address.
Server processes the request and sends back HTML, CSS, JS, and other resources.
Browser parses and renders the HTML/CSS, executes JS, and displays the page.

Question 5: Explain what a web server is and give examples of commonly used servers.
Answer: A web server is software or hardware that stores, processes, and delivers web pages to clients (browsers) over the Internet using HTTP/HTTPS. It handles requests from browsers and sends back HTML, CSS, JS, images, and other resources.

Common Examples:

Apache HTTP Server – Popular open-source server.

Nginx – High-performance, lightweight server.

Microsoft IIS – Web server for Windows environments.

Node.js – Server-side JavaScript runtime often used as a web server.

Question 6: Define the roles of a frontend developer, backend developer, and database administrator
in a project.
Answer:  Roles in a Web Project (Short Textbook Answer):

Frontend Developer: Designs and implements the user interface (UI) of a website or application using HTML, CSS, JavaScript, and frameworks like React. Ensures the site is interactive, responsive, and user-friendly.

Backend Developer: Builds and maintains the server, application logic, and APIs. Handles data processing, authentication, and communication between the frontend and database using technologies like Node.js, Python, or Java.

Database Administrator (DBA): Designs, manages, and maintains the database. Ensures data is stored securely, backed up, and efficiently retrievable. Optimizes database performance and manages access control.

Question 8: Explain the difference between static and dynamic websites. Provide an example of each.
Answer: Static vs Dynamic Websites (Short Textbook Answer):

Static Website:

Content is fixed and does not change unless manually updated.

Simple, fast, and easy to host.

Example: Personal portfolio site or a company’s brochure website.

Dynamic Website:

Content is generated on-the-fly based on user interaction or database queries.

Can be personalized and interactive.

Example: Facebook, Instagram, or an online shopping site like Amazon.
